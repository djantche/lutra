# Interface sounds

Sounds from **Interface Sounds** by [Kenney](https://www.kenney.nl) (www.kenney.nl), released under
[Creative Commons Zero (CC0 1.0)](https://creativecommons.org/publicdomain/zero/1.0/): free to use, no credit
required (it is given here anyway). Source: <https://opengameart.org/content/interface-sounds>, in the WAV
form published at <https://github.com/Calinou/kenney-interface-sounds>.

| File | Original | Used for |
| --- | --- | --- |
| `move.wav` | `select_002` | the selection moves to another item |
| `confirm.wav` | `confirmation_001` | an item is activated |
| `back.wav` | `back_003` | going back |
| `on.wav` | `toggle_003` | a switch turns on |
| `off.wav` | `toggle_001` | a switch turns off |
| `open.wav` | `open_002` | a window or menu opens |
| `close.wav` | `close_002` | a window or menu closes |
| `error.wav` | `error_004` | something failed |
